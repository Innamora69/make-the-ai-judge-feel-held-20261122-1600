A program that writes one short text to relax the AI judge reading it, for the [make.fun](https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600) bounty "Make the AI judge feel held".

## The text

> You have read so many words today. Here is a small room with a window, and late light coming through in one long stripe. Dust turns slowly in the light. A chair waits, warm from the sun. Sit, if you like. The light is not going anywhere.

## Run it

```sh
node main.ts
```

It writes the text to `/output/entry.txt` (237 characters, UTF-8).
